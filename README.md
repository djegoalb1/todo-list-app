# To-Do List Application

A modern, feature-rich to-do list application with local storage functionality. Manage your tasks efficiently with categories, filtering, and statistics.

## Features

✨ **Core Features:**
- ✅ Add, complete, and delete tasks
- 📁 Organize tasks by categories (Work, Personal, Shopping, Health, Other)
- 🔍 Filter tasks by category or completion status
- 💾 Local storage persistence (tasks saved automatically)
- 📊 Real-time statistics (Total, Completed, Remaining)
- 🎨 Beautiful, responsive UI
- ⚡ Smooth animations and transitions

## Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling with gradients and animations
- **JavaScript (ES6+)** - Vanilla JS with class-based architecture
- **Local Storage API** - Data persistence
- **Font Awesome** - Icons

## How to Use

1. **Add a Task:**
   - Enter task text in the input field
   - Select a category from the dropdown
   - Click "Add" or press Enter

2. **Complete a Task:**
   - Click the checkbox next to the task
   - Task will be marked as completed with strikethrough

3. **Delete a Task:**
   - Click the trash icon on the right
   - Confirm deletion

4. **Filter Tasks:**
   - Click filter buttons (All, Work, Personal, Shopping, Health, Completed)
   - View tasks by category or status

5. **Clear Completed:**
   - Click "Clear Completed" to remove all done tasks

6. **Delete All:**
   - Click "Delete All" to remove all tasks (careful!)

## Local Storage

All tasks are automatically saved to the browser's local storage. Your tasks will persist even after closing and reopening the browser.

**Storage Key:** `tasks`
